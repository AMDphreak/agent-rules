# Writing: News vs Blog

House stance (titles + purpose):

- **News** faces **outward** — what entered the shared record (shipped, added, partnered).
- **Blog / essay** faces **inward** — ideas, craft, philosophy, tutorials, thinking in public.
- Site title rules still win: each site's `STYLE.adoc` / `AGENTS.md`. Philosophy: *Titles as orientation*.

## Mode selection

1. If the user names a mode, use it.
2. Else infer:
   - **News** — announcement, ship note, partner/event record, press-style update, inverted-pyramid brief.
   - **Blog** — argument, tutorial, essay, opinion with evidence, conversational long-form.
3. If still ambiguous, ask once: news or blog?

Then read the matching file and follow it:

- News → [news.md](news.md)
- Blog → [blog.md](blog.md)

Optional: published skill suites and further references → [published-sources.md](published-sources.md).

## Quick checks (both modes)

- Prefer concrete nouns, metrics, and named sources over vibe adjectives.
- Do not invent facts, quotes, or expert predictions.
- Match the repo's existing voice and AsciiDoc/Markdown conventions when editing in-tree.
